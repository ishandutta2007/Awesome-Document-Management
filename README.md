# Awesome-Document-Management

Top Document Management EcosystemCurated List of SaaS Products & Open-Source GitHub ProjectsFocused on Enterprise Content Management, File Collaboration & Digital ArchivingLast updated: September 2026This repository tracks notable SaaS platforms and open-source projects for Document Management. These tools organize, store, version, and secure documents across teams, enabling collaboration, compliance, and efficient information retrieval for businesses of all sizes.Examples include Microsoft SharePoint, Box, Dropbox Business, Egnyte, M-Files, DocuWare, OpenText Content Cloud, Alfresco, Zoho WorkDrive, and Google Drive (the category leaders).Open-source emphasis: This section is expanded with active projects for self-hosting, custom metadata schemas, and transparent content governance — ideal for organizations seeking data sovereignty and vendor independence. The open-source ecosystem in 2026 is anchored by Nextcloud (full productivity suite), Mayan EDMS (enterprise document management), and Paperless-ngx (paperless archiving), with strong coverage in PDF processing, digital signing, and collaborative file sharing.Contributions welcome!
